# AI Based Coding Mentor

## Project Overview
AI Based Coding Mentor is an intelligent learning platform designed to help beginner programmers learn coding easily. It provides step-by-step explanations, code analysis, syntax error detection, practice questions, quizzes, and progress tracking.

## Features
- User Registration and Login
- Multiple Programming Language Support
- Online Code Editor
- AI-Based Code Analysis
- Syntax Error Detection and Explanation
- Step-by-Step Learning
- Chapter-Based Courses
- Practice Questions and Quizzes
- Student Progress Tracking

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- AI / Machine Learning

## Project Modules
1. User Authentication
2. Language Selection
3. Course Learning
4. Code Editor
5. AI Code Analysis
6. Quiz and Practice
7. Progress Tracking

## Installation and Execution

1. Clone the repository:
   `git clone https://github.com/rjeevaruthika-del/AI-Coding-Mentor-New.git`

2. Open the project folder:
   `cd AI-Coding-Mentor-New`

3. Install required packages:
   `pip install flask`

4. Run the application:
   `python app.py`

5. Open your browser and visit:
   `http://127.0.0.1:5000`

## Project Goal
To make programming easier for beginners through AI-powered guidance, interactive learning, and personalized feedback.
